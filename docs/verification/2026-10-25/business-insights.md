# 运营分析功能本地验收

环境：Windows Docker Desktop；Java 17 / Maven；PostgreSQL 16；Redis；隔离的 API / 前端 / Mailpit。仅合成账号、项目、调用数据，不连接生产数据库，不向真实邮箱发送邮件。

## 自动化覆盖

最终结果：后端 `mvn verify` 144 项测试通过，无失败、错误或跳过；前端 26 项测试通过，类型检查、生产构建、生成示例同步检查通过。

- 既有完整后端回归与新增 `InsightsIntegrationTest`。
- 费用只计算生成类 Observation，不重复计算 Trace 中的费用；缺失价格、缺失用量、零基线及保留期不完整时不伪造比较结果。
- 未登录、跨账号、套餐限制、CSRF、非法分组和无效时区。
- 发布标记创建、删除、审计、未来时间拒绝及新发布前后等长窗口。
- 周报并发生成唯一性、同周重试去重、报告写入失败回滚邮件入队、故障恢复。
- 退订、邮箱变化、套餐降级、项目删除后的邮件发送拦截；普通通知仍可发送。
- 夏令时与下次周一时间、预览时区、开启订阅不立即发信；邮件链接使用配置的网站地址。
- 外层写事务中的分析读取独立连接池，仅看到已提交快照。

## 浏览器实测

- 桌面 1920×1080：费用诊断三个分组、最高费用调用分页、发布窗口选择、手动保存本地时间转换 UTC、未结束窗口提示。
- 示例费用从 0.36 USD 增至 1.35 USD，调用数维持 30，均价变化 275%，平均输入变化 150%，P95 变化 87.5%，失败比例 10%；与合成数据吻合。
- 将其中一次模型调用价格改为未知后：覆盖率 96.67%，仅展示已知费用 1.305 USD，均价为未知、费用变化不再给出百分比。
- Free 显示套餐入口，不能读取付费诊断。恢复 Core 后可继续查看。
- 周报默认未开启；预览 Asia/Shanghai 上一个完整自然周，开启后显示下次周一 09:00 对应 UTC 时间。
- 在隔离数据库推进订阅任务到期后，Worker 实际生成邮件并投递到 Mailpit。正文统计与预览一致，控制台显示“已发送”，历史快照可打开；退订后显示“未开启”。
- 手机 390×844：指标单列、表单折行，文档宽度不超过视口；宽表格仅在内部容器滚动。浏览器无 JavaScript 错误。
- 最终构建复验：顶部刷新会重新计算诊断；带项目参数进入后仍可切换项目，地址和数据保持一致。新版实际邮件数值去除多余末尾零，诊断与退订入口均使用配置的网站地址。

## 边界

这是本地合成数据验收，不等于生产邮件收件箱送达率、真实流量性能或业务收益验证。上线需更新 API、Worker、前端并应用 V15 迁移；不会自动给既有账号开启周报。功能公式及保留规则见 [功能说明](../../business-insights.md)。
