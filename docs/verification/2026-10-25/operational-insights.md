# 预算提醒、失败与慢调用、手动周报本地验收

环境：独立 PostgreSQL 16、Redis、API、前端、Mailpit；仅合成 Core / Pro / Free 账号与测试项目，不连接生产账号、不向外部邮箱发信。

## 自动化

最终本地结果：后端 `mvn verify` 151 项测试通过，无失败、错误或跳过；前端 26 项测试、类型检查、生产构建和生成示例同步检查通过。

`InsightsIntegrationTest` 新增预算和调用分析场景，覆盖：

- 请求与模型调用分开计数，取消不算失败，缺失耗时不补零，失败率与慢调用率使用正确分母，分位数和分页准确。
- 分组白名单、无效阈值/分页、未登录及跨账号访问拒绝；Core 固定慢调用阈值与提醒线，Pro 自定义，Free 可关闭已有提醒。
- 月预算金额/精度校验，UTC 自然月切换，生成类模型费用只计一次，提醒类型按月去重。
- 价格不完整或月初时间不足时不预测；数据足够后可生成预测超预算提醒。
- 预算邮件入队及记录写入失败整体回滚，并发重试只生成一份；账号邮箱变化、项目删除、套餐降级及关闭提醒后拦截待发邮件。
- 手动周报入口的会话、CSRF、所有权、套餐、订阅校验，同周重复点击不重复生成，不移动定时发送时间。

## 浏览器与邮件

- 桌面 1920×1080：30 条请求，3 次失败，10 条 8 秒慢调用，失败率 10%、慢调用率 33.333%、P95/P99 8 秒，与合成数据吻合。慢调用分页、排序和有效 Trace 详情（2 个对象）跳转通过。
- Pro 选择模型调用、模型分组及 1 秒阈值后，30 条模型调用均为慢调用；自定义 70% 预算提醒线保存成功。Core 相应输入禁用，后端也拒绝越权配置。
- 2 美元月预算，已知模型费用 2.07 美元；Worker 实际发送“已达预算”提醒到 Mailpit，页面显示已发送、当时预算和费用，邮件包含覆盖率、预测限制和项目入口。
- 周报按钮主动入队后实际投递到 Mailpit；第二次点击提示已有记录，数据库仅有一份当周周报，下次发送时间保持不变。
- 一条模型费用设为未知后，已知小计变为 2.025 美元、覆盖率约 98.889%，月末预测显示未知，并提示先补齐价格。
- 降级 Free 后不能查看分析或开启提醒，但可关闭已开启预算提醒，页面显示待发送邮件已取消。
- 手机 390×844：指标单列、表单折行；页面宽度 375px（视口390px扣除滚动槽），宽表格在 241px 容器内滚动，未造成页面横向溢出。周报新增按钮同样无溢出。新验收标签页无 JavaScript 错误。
