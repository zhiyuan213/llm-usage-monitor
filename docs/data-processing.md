# 数据处理与保留说明

核实日期：2026-10-30。对应公开页面 `/security#data-handling`，本文描述实现，不是已签署 DPA 或合规认证。

## 数据流和服务提供方

应用直接调用模型供应商；MeterTrail 仅异步接收上报元数据，不代理模型调用，不要求 prompt/回答正文。客户主动上报的 ID、时间、状态、耗时、供应商、模型、用量、Score 和客户/用户/功能标签用于统计。不要上报秘密，建议使用化名标识。原生 usage 适配只接受文档允许的数字字段。

基础设施和事务邮件使用腾讯云。当前生产服务位于新加坡；这不是可选数据驻留或区域隔离保证。Creem 处理当前相应支付，历史 Paddle 交易记录仍可能存在；GitHub 用于可选登录，GA4 只在同意后用于公开页统计。支付平台处理完整银行卡资料。供应商可能跨境处理必要数据；完整合同子处理方登记和签署 DPA 流程尚未提供。

## 保留与删除

| 数据 | 当前实现 |
| --- | --- |
| 分析明细和费用记录 | 当前套餐滚动窗口：Free 30天、Core 90天、Pro 3年；付费结束后保留设置有30天宽限，之后适用 Free；删除项目后异步移除 |
| 审计记录 | `audit_logs` 独立于分析保留窗口；当前无固定自动到期清理期限；项目/账号删除后保留，不承诺永久存储或固定年限；支持 Excel/PDF 导出 |
| 支付与安全记录 | 按必要业务、安全和争议处理用途另行保留；不能等同分析明细窗口 |
| 批次/事件处理记录 | 已处理事件与已完成批次约8天后清理；不等同 Trace 明细保留 |
| 备份 | 访问受限，不用于日常分析；当前未承诺固定备份淘汰期限，不宣传即时删除全部副本 |

用户可在账号安全申请注销；项目删除立即撤销密钥，明细异步删除。先导出必要记录。访问、更正或删除请求联系 `13428961230@163.com`，核实账号归属后处理，必要支付、安全与审计用途可能限制删除。

不宣传“每个动作都记审计”：仅已接入审计的账号/工作空间操作会记录，模型事件与普通读取不是全部操作审计。SSO、SIEM、发票对账、GDPR/HIPAA 认证、SLA 均未包含。审计固定保留周期及备份淘汰规则仍列待办，未在本次修改中添加删除任务。

## 功能口径

- 告警：工作空间所有者账号邮箱收信，每分钟看最近一小时，同一对象版本通知一次；一小时冷却内收集新证据。错误统计、最大耗时和已知正费用针对当前匹配对象，Trace 与 Observation 可能分别计入，不是概览单次 Observation 慢调用统计。
- 预算提醒：发送到所有者已验证邮箱，按项目 UTC 自然月的模型费用提醒；与告警相互链接，二者都不会扣款或限制接入。周报仍由用户主动开启。
- 客户归因：读取每个对象自己的 `data.customerId`；不会从 Trace 自动继承。Trace 和相关 Observation 均需填写。`userId` 和 `feature` 同理。无标签的历史数据不会自动补齐。
- 套餐：审计导出、客户/用户/功能分组、自定义价格为已有公共能力；Core/Pro 增加付费分析和提醒，Pro 再增加分析留存与阈值定制，不把公共能力包装成 Pro 独占。
