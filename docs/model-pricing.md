# 自动模型价格与项目覆盖

公共价格由 worker 启动后约15秒首次拉取，此后默认每6小时同步一次。API 进程不执行同步。默认来源为 [Models.dev](https://models.dev/) 的公开价格目录（https://models.dev/api.json），这是第三方公开目录，不是供应商账单接口。费用是估算值。

## 匹配顺序

1. 根据请求 `startedAt`，匹配同项目、同 `provider`、同 `model` 已生效的最新自定义版本。
2. 没有自定义版本且项目开启公共价格匹配时，匹配同供应商、同模型的公共版本。
3. 未匹配、价格不支持或用量不完整时，费用为未知，不当作0。模型名称相同但供应商不同不会串用价格。不做模糊名称匹配。

项目设置可关闭“自动匹配公共模型价格”。私有部署如果沿用了公共供应商和模型名称，必须关闭该选项，以免套用公共托管服务的费率。使用独立的私有供应商标识时，无公共匹配便自动保持未知。自定义价格属于当前项目，不影响其他用户。

公共目录更新只追加版本，不更新 `objects` 或 `cost_entries`。调用保存价格版本 ID 和实际使用的输入、输出、缓存费率；公共目录变价、删除模型和同步失败均不会重算历史费用。已有的显式更高 revision 修正流程不变，原样重试不重新计价。

默认目录未给出价格的官方生效时间，因此第一次发现或发现变化的同步时刻作为生效时间，**不猜测或回填此前价格**。首次同步之前的调用可能仍为未知。缺少缓存费率时，只能计算缓存命中为0的调用。尚不能用当前三项 Token 协议表达的阶梯、缓存写入等价格，不从复杂价格中随便挑基础价；保留未知，可由项目覆盖处理。未证实的输入、输出均为0的条目不导入。

## 分时价格

项目设置中的“公共模型价格表”展示当前已生效的最新公共版本，支持供应商筛选、模型名称搜索、服务端分页。模型行可展开查看来源、获取时间和分时费率；基础费率与时段覆盖分别列出。已配置项目价格时显示“自定义覆盖”，关闭公共匹配时该表仅供参考。历史、未来和不可用版本不会混入当前列表。接口为 `GET /api/projects/{project}/public-prices?q=&provider=&page=0&size=25`，要求项目所有权，页容量最多100。

平台可通过 `MODEL_PRICE_CATALOG_URL` 配置完整的标准化价格源，以提供带官方生效日期和分时规则的目录。应由平台维护该源；普通用户无需配置。默认 Models.dev 数据未提供每日分时规则，不会据此编造峰谷价格。对已知有分时价但来源尚不能表达的模型，平台应在标准化源中提供完整规则后再开放自动计价。

标准化源为完整快照，格式如下（下面全是测试价格，不代表供应商实际价格）：

```json
{
  "schemaVersion": 1,
  "prices": [{
    "provider": "example",
    "model": "example-model",
    "effectiveAt": "2026-10-28T00:00:00Z",
    "inputRate": 2,
    "outputRate": 4,
    "cachedRate": 0.5,
    "timeBands": [{
      "timezone": "Asia/Shanghai",
      "start": "22:00",
      "end": "06:00",
      "inputRate": 1,
      "outputRate": 2,
      "cachedRate": 0.1
    }]
  }]
}
```

所有费率是 USD / 百万 Token。按请求开始时间转换到 IANA 时区后选择时段；开始包含、结束不含，支持跨午夜和夏令时，精度为分钟。未落入任何时段时使用该版本的基础费率。同一版本的时段使用相同时区，不允许重叠；`24:00` 只能用作结束值。变价需新建 `effectiveAt`，已发布的版本禁止改写。正常价格回退或优惠结束也要追加新的版本。

私有项目可在设置中填写基础价格及一个分时时段；API `POST /api/projects/{project}/prices` 支持 `timeBands` 数组（最多24段），字段同上。相同供应商/模型的项目价格整体覆盖公共规则；不会把自定义基础价和公共峰谷价混在一起。

## 同步与运行

- `MODEL_PRICE_SYNC_ENABLED=true`，`MODEL_PRICE_SYNC_INTERVAL_MS=21600000`。
- 仅允许不带用户信息或查询参数的 HTTPS 源；不跟随重定向。连接超时10秒，请求超时30秒，响应上限8MB。不传项目数据或用户凭据到价格源。
- 校验完整快照后，在一个数据库事务和跨 worker 锁内写入。失败时回滚，保留此前有效版本并记录 `failed`，下个周期再尝试；不无限重试。
- 快照中移除或不再支持的模型追加不可用版本，后续调用保持未知，旧版本和费用证据保留。空或无效快照拒绝整批导入。
- 项目设置显示同步状态、模型数和最近成功时间。`GET /api/projects/{project}/pricing-status` 需项目所有权；`POST .../pricing-policy` 使用 `{"publicPricing":false}` 关闭公共匹配，需 CSRF 和所有权验证。
- 更换价格源之前应验证币种、单位、时间规则和支持范围，不能把供应商不同地域、批处理、阶梯等费率当成统一线性价格。

## 验证

`ModelPricingIntegrationTest` 使用实际 PostgreSQL，覆盖公共版本、自定义覆盖、私有隔离、跨午夜边界、同步幂等与回滚、未知缓存价格、真实 ingest→worker→费用证据和接口所有权。后端完整检查使用 `mvn -B -f backend/pom.xml verify`，不能只用该定向测试代替。
