# MeterTrail 页面样式规范（当前基线）

生效日期：2026-10-22。适用于官网首页、价格、开发文档，以及后台控制台全部页面。后续新增或更新页面默认沿用本规范；用户明确要求的新设计优先，接受后同步更新本文和样式文件。

## 实现依据与边界

- 官网样式入口：`frontend/src/public-v2.css`，作用域 `.public-v2`。
- 后台样式入口：`frontend/src/console-v2.css`，作用域 `.ui-v2`。
- 公共基础样式：`frontend/src/style.css`。优先复用现有组件和上述作用域内规则，避免新增全局覆盖影响另一套页面。
- 当前实现是尺寸和响应式细节的依据。本文没有列出的细节先查看现有同类页面，不另造一套视觉方案。
- 仅调整样式时保留接口、权限、登录态判断、表单校验与提交、筛选、分页、导出和跳转行为；展示真实数据与空状态，不写死设计稿中的示例数据。

## 通用视觉

| 项目 | 规范 |
| --- | --- |
| 字体 | 本地 `MeterTrail Noto Sans SC`，资源位于 `frontend/public/fonts/`，允许合成粗体；代码用现有等宽字体 |
| 主色 | `#3156E8` |
| 卡片 / 控件圆角 | 8px / 6px，首页预览卡片沿用现有 10px |
| 标准按钮 | 高度 36px、字号 14px、最小宽度 112px；同一工具栏按钮尺寸一致 |
| 危险操作 | 红色，与普通同类操作保持相同尺寸和结构；不得靠改变大小区分 |
| 布局 | 文字、输入框、按钮按统一基线对齐；输入框必须有可用宽度，不因 flex/grid 收缩成细条 |
| 状态 | 保留加载、禁用、错误、空数据和键盘焦点反馈，不能只做静态正常态 |

## 官网

- 内容最大宽度 1280px，居中；顶部导航高 72px，当前栏目以主色及底部细线标识。品牌在左，主要入口及语言切换在右。
- 官网语言切换随页头滚出视口，不使用 fixed 悬浮于正文；控制台顶栏的语言控件保持原有行为。
- 首页：浅蓝底双栏首屏，左文案右平直仪表盘预览；主标题 42px，正文 16px；四列功能介绍；底部浅色行动卡片。窄屏按现有断点转为单列或两列，不挤压内容。
- 价格页：介绍标题 32px，三个等宽套餐卡片，价格 38px；Core 推荐标识放卡片内部右上；按钮等高等宽；下方保留完整分段计费表及说明。
- 开发文档：左目录 224px，右正文，间距 40px；主标题 28px；快速开始用两列编号步骤卡片；语言标签、代码标题与复制按钮沿用当前样式，长代码完整展开，正文外层统一纵向滚动。
- 页脚统一品牌、说明及隐私 / 条款 / 退款链接；按 2026-10-25 用户要求，在退款右侧追加“开发工具”（英文 Developer tools），新标签页打开 https://basaltkit.com/。未经明确要求不重新加入代码仓链接或联系方式。
- 保留登录态加载完成后再显示对应入口的行为，避免访客按钮闪变。

## 后台控制台

- 费用诊断、发布对比、自动周报沿用 V2 卡片、工具栏和分页。指标桌面四列、窄屏单列，表格滚动仅限容器内部。侧栏项目导航可独立滚动，底部账号入口保留。未知费用与无法比较使用明确空值，不展示为零；周报默认关闭。
- 预算提醒、失败与慢调用延用上述分析页结构：筛选表单、指标卡、分组及具体调用列表；错误信息纯文本换行。预算邮件须主动开启，页面明确区分提醒与扣款/限额。周报测试邮件按钮排在示例按钮右侧，提交期间禁用，结果显示已入队或一分钟冷却提示。

- 侧栏宽 224px，背景 `#12213D`；导航字号 14px、图标 18px、行高至少 42px；项目 / 账号分组居中并配细分隔线；概览栏目名称保持“概览”。
- 顶栏高 56px；桌面内容区左右留白 32px。页面背景 `#F5F7FB`，白色卡片；页标题 24px、分区标题 16px、正文与控件 14px、辅助信息 12px。
- 标准按钮沿用通用尺寸；验证码等较长按钮最小宽度 144px。表格行内操作按当前 V2 使用文本链接，普通主色、危险红色；项目名称和对象名称保留链接表现，不改成按钮外观。
- 列表工具栏位于表格上方，导出 Excel / PDF 按钮在右侧；有筛选栏时与筛选、搜索控件同排。时间字段放最后；存在行操作列时放操作列之前。
- 独立字段分列显示，例如调用名称和对象 ID；长内容按当前规则截断或滚动，并保留必要的完整值查看能力。
- 所有分页均可选择每页 10、25、50、100 条，默认 25 条；记忆用户选择，兼容旧页面容量 5 条；每页条数标签、下拉框、总数、页码及翻页按钮横向对齐，窄屏合理折行；筛选或页容量变化后页码必须有效。
- 概览：四个指标卡、趋势与成本分布、最近活动；保持紧凑层级。活动区右上只保留 Excel / PDF 导出，不再显示“查看调用”。删除日期下重复的范围文字、环境与项目名称和“保留期内数据 · UTC”；项目仍从页头选择。
- 共用日期筛选始终显示开始与结束日期（UTC、结束日期包含当天）。快捷日期只更新对应区间，点击始终可见的蓝色“查询”按钮后才查询；编辑日期切换为自定义、点击查询应用。选择自定义时默认当月1日至月末；未来部分不参与统计。概览、调用记录去掉筛选下方重复的时间范围和统计口径文字。
- 数据统计：桌面左侧为筛选及分页列表、右侧为 Token 用量柱状图，1100px 以下单列排列。维度可选客户 / 用户 / 功能；时间按 UTC 自然年或自然月，默认当前年，月份模式另选年份和月份。点击查询才应用筛选，导出使用已查询条件。图表展示整个查询范围 Token 用量前20个标识，横轴标识、纵轴 Token，不随列表翻页变化；未知用量不当作零，长标识保留完整提示。
- Token 柱状图柱条居中于标识槽位，宽度最多28个 SVG 单位，不随标识减少而拉宽；使用柔和蓝色渐变、小圆角及顶部用量标签，保留悬停和键盘焦点反馈。
- 图表右上角可切换 Token 用量 / 估算成本（USD），分别展示所选指标在完整查询范围内的前20名；同步变更纵轴、顶部数值和提示。成本刻度支持小数，未知成本不得显示为零；切换图表指标不改变列表、时间筛选或导出字段。
- 概览的紧凑布局仅用于已选项目的指标内容；未创建项目时，标题与“从第一个项目开始”空状态卡片使用其他项目页面相同的间距和页脚位置，切换页面不产生卡片位移。
- 工作空间概览：首字母头像、名称及套餐标识；接入状态、用量、项目数、账期四张浅色指标卡搭配图标；删除指标上方重复说明，接入状态旁提供悬停及键盘焦点提示解释暂停条件，用量以已用 / 总额度同排展示，不加套餐与加购额度文字；项目数显示有保留数据数 / 总项目数，账期日期与UTC时间同排。桌面四列，中等宽度两列，窄屏单列；名称和真实指标不得被截断。
- 账号安全：账号信息在上，修改邮箱与注销账号在下方左右排列。
- 项目设置：价格表单两排三列，提交按钮右对齐；项目资料保留在设置页。删除项目入口位于项目列表每行“更多”菜单；点击后在弹窗显示项目名称、删除影响、名称确认框及邮箱验证码，验证成功才删除。
- 套餐与账单：套餐在上，三个套餐卡片的操作按钮统一贴齐卡片底部，保留一致内边距，不随功能条目数量上下移动；下方两列依次为当月用量 / 加购额度与超额账单、账单记录 / 退款与抵扣，窄屏按此顺序单列排列。三个记录列表均使用标准服务端分页；卡片保留一致内边距。
- 默认数据量下尽量在 1920×1080 一屏展示完整，不能通过隐藏必要内容、取消分页或把字号缩得难以阅读来实现；记录增多时允许正常滚动。

## 后续更新验收

1. 修改前阅读本文及同类页面，复用现有卡片、工具栏、表单、分页和样式入口。
2. 检查 1920×1080 桌面及 390px 窄屏：无页面横向溢出、遮挡、控件挤压；空数据仍有完整结构。
3. 验证受影响的导航、语言切换、登录态入口、表单、筛选、分页及导出等行为；文档改动需检查语言示例与复制。无法验证的项目如实记录。
4. 前端改动执行适当测试及构建；涉及依赖、SDK 或文档示例时执行审计和生成示例同步检查。推送后按照根目录 AGENTS.md 核对同一提交的全部 CI。
5. 设计基线发生明确变化时，同时维护本文、`docs/ui-v2.md` 及相应样式文件，避免规范和实现分离。

## 状态字段的来源与显示

- 用户上报的 Trace / Observation `data.status` 和 Score `data.valueType` 原样展示，包括概览、调用记录、详情和筛选选项；不因界面语言改写。协议仍只接受现有允许值，本规则不放宽协议校验。
- 平台生成的密钥有效性、上报批次处理状态、审计操作结果按界面语言翻译；未知状态保留原值。批次中文：待处理、已完成、已隔离、已失败、已删除，英文保留状态码。
- 按用户 2026-10-23 明确要求，审计成功结果中文显示“成功”，英文显示 `successd`，不修改接口或持久化值。

## 面向接入用户的文档表达

- 默认先提供能完成首次接入的最小请求，完整上报 Header / Body 参数放在独立“接入字段”栏目，进阶示例折叠展示，不能要求用户一次理解全部事件类型。
- 参数说明只描述公开接口、业务含义及使用限制，不使用“data 表”等容易与数据库表混淆的措辞，不公开数据库结构、SQL、内部组件或内部校验实现。
- `data` 表述为“事件内容的 JSON 对象”。保留完整字段参考与限制，避免简化文案改变协议实际含义。

- REST 接口说明顺序统一为 URL → Method → Header 示例 → Body 示例 → Resp 示例 → 字段说明；Method 按真实接口填写，示例下方提供独立“接入字段”栏目链接。

- 开发文档左侧菜单顺序：快速开始、Rest接入、SDK接入、接入字段、查询状态接口、查询状态字段、错误与重试、性能与容量、安全。接入字段为独立栏目（`/docs#fields`），仅提供上报 Header / Body 参数表；Rest接入保留 URL、Method 和请求/返回示例，并链接接入字段。

- 文档示例中出现的每个 Header / Body / Resp 字段均须能在对应的接入字段或查询状态字段中查到；明确区分客户端自动生成的 HTTP 通用字段与用户填写的参数。字段限制必须有实际实现依据，不推测新增必填字段、长度或枚举。

- Rest接入、接入字段明确标注 POST 接收成功返回 HTTP 200，status 固定 pending、不是实时处理状态；按用户后续要求提供可选查询地址 GET https://metertrail.com/v1/batches/{batchId}，在独立“查询状态接口”栏目展示 URL、Method、Header、Body（GET 无请求体）、Resp；相邻“查询状态字段”栏目解释查询 Header、路径参数与响应字段。SDK 收到回执即结束，用户按需调用查询方法。

- 开发文档代码块不设置内部高度上限或纵向滚动条，内容随代码长度展开，长行自动换行；统一使用正文外层滚动。

- “接入字段”仅展示上报 Header 和 Body 参数，不展示响应或查询参数；上报响应 status 固定 pending 及可选实时查询方式在 Rest接入 Resp 区域说明。

- 支付页 `/pay` 沿用官网 V2 导航、页脚及居中卡片，窄屏按钮可换行；沙箱明确标注不真实扣款。前端完成事件仅作提示，套餐生效以后端验签回调为准。

- 2026-10-23 文档表格：桌面字段表随正文宽度换行，不设1000px最小宽度；正文与右侧滚动条保留24px间距和稳定滚动槽。窄屏右留白16px，六列表格保留720px可读宽度及必要横向滚动，不裁切内容。

- 2026-10-23 登录页底部“创建账号、忘记密码、验证邮箱”使用同一行链接组，字号/字重/行高一致（桌面14px，窄屏12px），空间不足时整项换行，不拆分链接文字。

- 2026-10-24 首页性能参考与文档“性能与容量”（`/docs#performance`）共享内容组件；数字旁保留本地短时测试范围及非线上承诺说明，窄屏指标单列，不把请求速率表述为并发用户数。

- 2026-10-24 账号分组新增“消息反馈”，仅管理员显示其下方“管理员 / 用户消息”分组；反馈列表与会话采用现有面板，首条消息在上、按顺序回复缩进显示其下，管理员回复浅蓝底。桌面左右布局，窄屏上下排列；纯文本换行，不渲染用户 HTML。

- 2026-10-24 官网新增“在线演示”和“接入教程”入口。演示明确标注虚构数据，支持请求筛选与详情，沿用 V2 指标卡与面板；窄屏上下排列。三篇教程使用现有代码块与复制交互，长代码自动换行。公开页面提供可拒绝、可撤回的统计偏好提示，不采集表单和账号内容。

- 自动周报页以订阅设置、下一次发送和发送记录为主；“查看周报示例”明确标注模拟数据，“发送测试邮件”不占正式周报名额且不改变时间。历史周报展示简洁摘要并链接费用诊断、失败与慢调用，不重复完整诊断表格。
- 周报邮件与网页示例沿用相同摘要指标和数字格式，邮件使用独立 HTML 模板、浅色指标卡和详情链接；邮件窄屏可用两列卡片。测试标识清楚可见，不能套用额度告警的来源说明。验证码与普通告警模板独立保留。

- 管理员“项目统计”仅管理员可见；账号、UTC 自然年/月筛选，默认当前年。左侧分页列出所有未删除项目（含无调用项目），列头可切换全结果升降序，未知 Token/成本始终排后；右侧复用统计图样式，按 Token/估算成本分别取前20项目，与分页独立。

- 2026-10-25 首页优先展示接入示例与费用排查场景；压测数字及测试条件仅在文档性能栏目展示。首屏提供具体 units 构成及条件化请求数示例；套餐说明如实区分历史保留与自定义阈值，不暗示 Pro 增加接入额度。访客显示免费开始，登录用户显示进入控制台，均保留无需登录演示。

- 2026-10-25 调用列表按 Trace 汇总关联模型、已知 Token、已知估算费用和价格覆盖数，费用/耗时/Token 排序作用于全部筛选结果。详情先展示请求摘要和价格依据，上报字段折叠并提供中文标签。概览趋势与 P95 仅统计 Trace 请求；日期使用 UTC、起点包含终点不含，概览/调用默认最近7天，统计保留自然年/月并增加快捷及自定义日期。诊断自定义本期最长30天，与之前等长区间比较。账单分列套餐额度、加购额度、总已用和套餐加购总剩余，不包含额外授权超额额度。

- 2026-10-25 接入状态由后端按订阅、账期、套餐/加购额度及授权超额状态计算，只描述新增对象；状态不可用时不显示正常。调用未知费用原因由后端证据分类，筛选与导出一致；按账号和项目保存列表查询及分页。分析空态区分无可查询记录、窗口为空、无模型步骤、费用不完整及超保留期，不能由空结果推断从未接入。工作空间项目操作精简为进入项目、接入和更多操作，最近活动按保留对象的开始时间展示。通知以服务商接收表述发送成功，不保证最终送达，预算草稿与保存配置明确区分。

- 调用记录工具栏搜索框桌面基准320px，不占满整行，状态和费用筛选紧随其后，导出靠右；700px以下搜索占一行，筛选和按钮正常换行。


## 2026-10-27 控制台可用性补充

- 调用记录在 760px 以下转为带字段标签的卡片；桌面保留表格，ID 缩略且可复制。其他宽表只在容器内滚动，不把英文单词逐字拆开。
- 快捷日期与自定义日期均保留查询按钮，选择日期不自动查询；数据统计自然年/月筛选保持原有点击查询行为。
- 分页默认 25 条，选项 10/25/50/100，记忆选择；独立列表各自分页。空列表隐藏翻页区但保留导出。
- 新增接入暂停在正文顶部说明原因和账单入口；不将拒绝新增对象等同于数据丢失。
- 新建密钥只在当前显示期间提供 cURL/Node/Python 示例，密钥不写入浏览器存储；保留验证码流程。

## 场景式接入文档（2026-10-27）
REST 与 SDK 使用相同的三种场景：单模型调用（Trace + Observation 同批）、多模型调用（步骤分批、最终 Trace）、可选评分（单独请求指向已有 Observation）。用带分支连接线的响应式示意图解释关联，不将上报批次误称为业务请求。SDK 各语言各场景提供完整代码及复制按钮，说明内存缓冲、flush 回执和自动批处理边界；窄屏示意图标签与描述上下排列。

- 工作空间四张指标卡的数值及其分母、时间后缀采用相同字号、字重和行高，桌面20px，窄屏16px。

### 概览请求浏览（2026-10-27）
