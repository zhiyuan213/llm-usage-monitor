## 本地验收依据

全栈冒烟测试通过真实 HTTP API 注册测试账号，从 Mailpit 获取验证码，创建项目及经过验证的 API 密钥，配置示例模型价格，然后上报 12 个 Trace、12 个 Observation 和 12 个 Score。测试轮询处理结果，重放完全相同的批次，并验证：

- 接收 36 个对象，计入 36 个用量单位（units）。
- 重放时识别出 36 个重复对象，**新增用量为 0**。
- 共 12 次模型调用、36,480 个已知 Token，模型估算成本为 **0.12705 美元**。
- 指定调用链能够返回对应的 Trace、Observation 和 Score。
- 账单、告警规则创建和审计接口返回实际持久化的数据。

告警检查最近一小时的事件，排除未来事件；上报时间最多允许快于服务器五分钟。每条规则持久化已通知的对象版本，同一证据不会因冷却结束或 worker 重启重复触发。一小时冷却期间检测到的新匹配数据会合并，即使事件时间随后退出窗口，也只补发一次。通知记录触发窗口的指标值、新匹配对象数和 UTC 事件时间范围。更高版本若仍满足条件，会被视为新证据。V8 升级会为已有通知补建去重记录。这是应用层告警去重；邮件服务商实际已接收但响应失败时，仍可能因重试重复投递。

本地测试账号仅保存在被 Git 忽略的 `.local/e2e-account.json` 中，不属于生产凭证，也未纳入提交。浏览器保留在本地应用页面，便于查看。

## 公开上线前必须完成的事项

1. **配置商户、OAuth、SMTP，并完成外部验收。** 验证真实 GitHub 登录与绑定冲突、真实事务邮件的送达情况，以及 Paddle 沙盒中的订阅、续费、支付失败、取消、退款、重复通知和乱序通知场景。配置产品价格 ID 和客户门户。仅在商户获批后启用正式支付接口。
2. **明确尚未确定的商业规则。** 包括附加包数量、价格、有效期、消耗顺序，升降级按比例计费，取消订阅后的访问权限，支付失败宽限期，退款和税费。当前付费流程会拒绝非活跃或已过期的订阅账期，不会自行假定这些商业规则。
3. **接通实际超额费用收取。** 已实现精确的用量与超额额度预留账本；已新增按账期冻结的结算意图、Paddle一次性收费、加购包付款后发放与退款回收；默认关闭，当前验证及启用要求见 [收费说明](usage-collection.zh-CN.md)。完成前不应对外销售自动收取超额费用的能力。
4. **证明容量与存储能力。** 对每批 1／50／500 个事件分别执行持续 30 分钟、每秒 1,000 个事件（EPS）的完整测试，并验证 3,000 EPS 突发流量、并发每秒 20 次查询（QPS）、服务重启和响应丢失场景。当前查询直接使用 PostgreSQL 中的标准化明细行；汇总表、分区和冷归档设施应根据实测需求建设。Pro 的实际明细保存在 PostgreSQL 中，三年保留的成本可行性及归档访问延迟尚未验证。
5. **完成生产运维验证。** 配置域名、DNS、TLS、真实指标与通知接收端，以及独立的外部监控；在真实环境中演练蓝绿切换与回滚；协调前端构建产物发布；核验镜像仓库中的不可变摘要。目前未部署云资源或公开生产接口。
6. **确认恢复与隐私政策。** 明确财务／审计数据保留期限、恢复目标、旧邮箱不可用时的账号恢复政策；完成一次加密异机恢复演练。政策页面已标明为模板，仍需补充运营主体、联系方式及适用司法辖区。

## 明确的范围选择

- 每个工作空间只有一个所有者；不包含团队邀请、网关、模型转售、SSO、Kubernetes 或 Enterprise 套餐。
- 三种对象共用一张逻辑对象表。Worker 使用事务范围的锁，而非心跳租约；事务回滚会立即释放任务。
- 不虚构模型价格、提示词正文、客户收入／利润率、供应商用量、已发布的 SDK 包、容量结论或 SLA。
- 所有测试和示例均使用本地合成数据；首页预览数字明确标记为示意。
